# Outline parsing strategy

Manual review: October 12, 2026. The source-structure, explicit-week, typed-plan and coverage-report adapters below are now implemented. Resource associations for nonweek entry numbers and calendar normalization remain future work. See OUTLINE_PARSING_RESULTS.md for the measured result.

## What the current coverage measures

All 1,739 Fall 2026 outlines were captured, across 156 subjects and 1,682 course codes. Before this pass, 497 outlines had explicit parsed weeks (28.6%). After recapturing all outlines with structure preserved, 775 have explicit weeks (44.6%) and 1,123 have a structured teaching plan of any supported kind (64.6%). Of those, 1,089 contain teaching-topic text; reference-only entries do not become topic vectors. The remaining classifications are 473 unsupported/prose plans, 100 external schedules and 43 outlines with no plan found.

“Successfully parsed outlines” needs a stated definition: explicit weeks and other structured teaching entries measure different things. Capture succeeded for every discovered outline; weekly extraction covers a subset. Residual text can include introductions, reading instructions, breaks, or external schedule references rather than missed teaching rows. These counts are from the local corpus; nine manually reviewed examples do not establish the frequency of each format across the full corpus.

## Implementation and remaining work

1. **Preserve structure before expanding regexes.** Capture a bounded DOM representation of the tentative-plan section using its stable heading ID, with heading-based fallback. Retain rows/cells, rowspan/colspan, paragraph and BR boundaries, links, and source locations. Expand table occupancy while preserving which cells were inherited. Do not duplicate merged topic cells into every week automatically. Keep unknown blocks for review. Capture version 4 now stores this structure, and every discovered outline was recollected successfully.
2. **Improve explicit weekly formats first.** Accept Unicode bullets, separated paragraph date labels, explicit week ranges, and multi-column tables with partial or blank headers. Require multiple consistent week rows and validate column roles before a headerless fallback; do not treat arbitrary numbered lists as weeks. Use both broad and detailed topic columns, keep references separate, and split recognizable assessments from teaching text. Add minimized fixtures from STAT 202, 850, 331, and 330. These adapters are implemented, with source-derived fixtures and a measured whole-corpus increase.
3. **Add typed schedule adapters.** Use `kind: week | lecture | module | unit | dated`, optional explicit number, literal date labels, topics, references, and source evidence. Keep breaks, assessments, tutorials, and external references in separate fields. CS 246 and PHYS 121 should become searchable teaching plans without manufacturing week numbers. Calendar-grid extraction is implemented for explicit month/year and weekday geometry; dates remain source labels.
4. **Connect types to search deliberately.** Embed teaching topics per entry, with chapter/course context where explicitly stated. Match a resource's `lecture_05`, `module_03`, or `unit_02` only to the same entry kind and number, with course/term/section checks. Keep existing week associations restricted to explicit weeks. A chapter-only reference should not be embedded as if its topic were known; obtain a source-grounded chapter-to-topic mapping separately. Calendar-to-week associations require explicit course scheduling evidence, including reading-week handling.
5. **Classify references and absence.** The report classifies `explicit-weeks`, `other-structured-plan`, `external-schedule`, `unsupported-or-prose`, and `no-plan`; prose and unsupported layouts are still combined. MATH 135 needs a separate authorized LEARN schedule-document reader; regex changes cannot recover unavailable data. ENGL 109 can contribute unit topics now while detailed timing remains external.

## Validation and reporting

Keep small source-derived fixtures with expected topics, reference/event separation, entry kinds, and evidence. Test negative cases: Lecture 5 is not Week 5; Module 3 spanning two weeks is not Week 3; reading-week rows are not topics; inherited deadline cells do not move into topic columns; chapter references do not imply chapter names.

All 1,739 pages were recollected and reparsed; future adapter changes can be applied offline to their saved bounded schedule structures. Audit a stratified sample from each layout across subjects, and retain a holdout set while tuning adapters. Report precision and coverage by schedule kind, including supported entries with no meaningful topic text, instead of a single weekly-success percentage. Rebuild affected embeddings only after extraction passes review, preserving source identity and deterministic cache reuse.

An LLM fallback, if added later, should receive only the bounded plan section, return the same typed schema, and cite exact source spans. Reject unsupported numbers/dates/topics and keep uncertain entries out of resource-number associations. It should follow structural adapters rather than replace them.
